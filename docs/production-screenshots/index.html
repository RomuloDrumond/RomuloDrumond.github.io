How to read the differences

Desktop captures use 1536 × 960 CSS pixels and 1280 × 800 PNGs. Fresh mobile captures use the browser's native 390 × 844 viewport and 780 × 1688 PNGs. These are viewport screenshots, not full-page captures. Desktop local references come from the reviewed source tree; the production release has the identical tree, and a fresh local home capture reproduced its reference exactly.

Original PNGs retain their embedded color profiles. Pixel measurements convert both sides to sRGB first. One pair is pixel-identical; the largest mean channel difference is 0.710 / 255. Remaining differences include generated responsive-image encoding, color-profile rounding, and transient caret/sidebar/progress/back-to-top states. Original image bytes are unchanged. No visual regression was observed in the checked routes and states; pixel identity is not the pass criterion.

Evidence and limits

Clipboard read-back on production is blocked by the background browser's focus restriction. The earlier local clipboard test passed, and the deployed code assets match the successful build. External iframe playback and repository-card uptime still depend on their providers. The Docker/devcontainer environment was not exercised.
